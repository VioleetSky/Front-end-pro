Мета: Створити невеликий застосунок, який показує погоду для введеного міста, з можливістю додати місто у “вибрані”.

Основний функціонал
Пошук міста
Інпут для введення назви міста.
Після натискання кнопки “Пошук” — завантажується погода через API.
Якщо місто не знайдено — показати повідомлення про помилку.

Відображення погоди
Назва міста, країна.
Поточна температура, вітер, опис погоди.
Прогноз на кілька днів (мін/макс температура).

Обране
Кнопка “Додати в обрані” / “Видалити”.
Обрані міста зберігаються у localStorage.
Можна швидко натиснути на обране місто, щоб оновити погоду.

Компоненти
<App /> — головний компонент
<SearchBar /> — інпут і кнопка пошуку
<WeatherCard /> — показує погоду для поточного міста
<FavoritesList /> — список обраних міст

Використати
React Hooks: useState, useEffect
Робота з API: fetch
Збереження в localStorage
Умовний рендеринг (Loading / Error / Empty)

Додатково (опціонально)
Додайте кастомний хук useWeather.
Зробіть фон, що змінюється залежно від погоди (сонячно, дощ, сніг).
