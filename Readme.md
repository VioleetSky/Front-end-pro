У цьому завданні створюється об’єкт user з різними типами властивостей, включаючи вкладені об’єкти та масиви. Також виконуються операції доступу до вкладених значень та вивід у консоль ключової інформації.
Що потрібно зробити:
Створити об’єкт user з такими властивостями:
name — рядок (ім’я користувача)
age — число (вік)
isOnline — булеве значення (чи користувач онлайн)
friends — масив з 3 імен друзів
settings — вкладений об’єкт з полями:
theme — рядок: "light" або "dark"
notifications — булеве значення: чи увімкнено сповіщення

Створити окрему змінну firstFriendName, яка отримає ім’я першого друга з масиву user.friends.
Створити змінну notificationsEnabled, яка отримає значення з user.settings.notifications.

Вивести в консоль:
Ім’я користувача
Кількість друзів (через .length)
Ім’я першого друга
Поточну тему оформлення (з user.settings.theme)
Чи ввімкнені сповіщення
