Ця програма збирає дані від користувача через браузерні вікна prompt та confirm, створює об’єкт session
Програма:
Отримує ім’я користувача через prompt (тип: string)
Отримує вік через prompt і перетворює його в number
Запитує, чи хоче користувач отримувати сповіщення (confirm → boolean)
Присвоює фіктивний userId типу bigInt (1234567890123456789n)
Встановлює lastLogin як null
Створює поле nickname, але залишає його undefined
Додає масив favoriteTech з трьох обраних технологій (тип: array)
Додає вкладений об’єкт settings з такими полями:
theme (значення: "dark" або "light")
autoLogin (значення: false)
У результаті формується об’єкт session, який включає всі вищезгадані поля.
Виводимо:
alert з короткою інформацією: "Привіт, [ім’я]! Ваш ID: [userId]"
У console.log — весь обʼєкт
У console.log — тип кожного поля (через typeof)
